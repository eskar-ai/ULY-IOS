Enable the keyboard

  1. Settings → General → Keyboard → Keyboards → Add New Keyboard…
  2. Choose Uyghur ULY keyboard
  3. Tap the globe key while typing to switch

Typing tips

  • Long-press e / o / u → ë ö ü
  • Long-press c / s / z / g / n → ch sh zh gh ng
  • Tap ◐ on the suggestion bar for System / Light / Dark theme
