What is ULY?

ULY (Uyghur Latin Yëziqi, 2008) writes Uyghur with Latin letters. Each Arabic letter maps to one Latin letter or digraph. This page helps you read both sides and start typing with ULY Künupka.

Digraphs and special letters

  • ch sh zh gh ng are each one sound — two Latin letters, one Arabic letter.
  • ë ö ü (not e o u alone) match ې ۆ ۈ. On the keyboard: long-press e / o / u.
  • Apostrophe ' stands for ئ inside words (e.g. jem'iyet).
  • q / x / gh are not the same as k / h / g — keep them distinct.

Short tutorial

  1. Learn vowels first

    Memorize a e ë i o ö u ü with their Arabic pairs. Most words are built around these eight vowels.

  2. Add common consonants

    Practice b p t d s sh l m n y — then digraphs ch gh ng. Read a short word letter by letter.

  3. Read Arabic → write Latin

    Cover the Latin side of the chart, look at an Arabic word, and write the ULY form. Check against the examples below.

  4. Type on the keyboard

    Enable Uyghur ULY keyboard, type the Latin form, and use suggestions to confirm spelling. Long-press for ë ö ü and digraphs.

Typing on Uyghur ULY keyboard

  • Long-press e / o / u → ë ö ü
  • Long-press c / s / z / g / n → ch sh zh gh ng
  • Tap a suggestion to complete or correct a word.
