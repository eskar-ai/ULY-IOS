ULY Künupka

Uyghur Latin Yëziqi keyboard for iPhone — offline.

iPhone 维吾尔语拉丁字母（ULY）键盘 — 离线使用。

Privacy Support

Enable the keyboard

  1. Install from the App Store
  2. Settings → General → Keyboard → Keyboards → Add New Keyboard…
  3. Choose ULY Künupka
  4. Tap the globe key while typing to switch

启用键盘

  1. 从 App Store 安装
  2. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘…
  3. 选择 ULY Künupka
  4. 打字时用 🌐 切换键盘
