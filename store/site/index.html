Private by design

Keyboards handle your private text. ULY Künupka is built so typing stays on your iPhone.

  • Suggestions and spell check run offline on your device.
  • Full Access is not requested — your keystrokes are not sent to us.
  • No account, no ads, no analytics SDK in the current app.
  • Source code is public so anyone can review how the keyboard works.

Open source

If you want to see the open-sourced code, visit the GitHub repository.

Enable the keyboard

  1. Install from the App Store
  2. Settings → General → Keyboard → Keyboards → Add New Keyboard…
  3. Choose ULY Künupka
  4. Tap the globe key while typing to switch
