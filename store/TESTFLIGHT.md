# TestFlight notes

## What to Test (paste into TestFlight)

```
ULY Künupka — offline Uyghur Latin keyboard

1. After install, open the app and read the enable steps.
2. Settings → General → Keyboard → Keyboards → Add New Keyboard → ULY Künupka.
3. Open Notes, tap the globe key, select ULY Künupka.
4. Type: uygh → tap suggestion "uyghur".
5. Type: bugun → confirm spell suggestion offers "bügün".
6. Long-press e / o / u for ë ö ü.
7. Tap ◐ on the suggestion bar to switch Light / Dark / System theme.
8. Confirm typing works in airplane mode (offline lexicon).
```

## Internal vs external

- **Internal:** up to 100 team members, no Beta App Review  
- **External:** requires Beta App Review; use same enable instructions in **Beta App Description**

## Known limitations to mention

- Keyboard must be enabled manually in Settings (Apple requirement for all third-party keyboards).  
- Personal learned words are cleared if the keyboard is removed.  
- iPad layout uses the same keyboard UI (phone-style); optimized for iPhone first.
