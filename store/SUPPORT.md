## ULY Künupka Support

Thanks for using ULY Künupka.

### Enable the keyboard

1. Install and open **ULY Künupka** once  
2. iPhone **Settings → General → Keyboard → Keyboards → Add New Keyboard…**  
3. Select **ULY Künupka**  
4. While typing, tap the **globe** key to switch keyboards  

### Typing tips

- Long-press **e / o / u** for **ë / ö / ü**  
- Long-press **c / s / z / g / n** for **ch / sh / zh / gh / ng**  
- Tap **ëöü** for more ULY characters and apostrophe  
- Tap **◐** on the suggestion bar to change theme (System / Light / Dark)
